# ☕ Kafe Digital - Cafe Self-Ordering System

Sistem Pemesanan Mandiri & Manajemen Kafe Berbasis Web menggunakan Laravel.

## 🚀 Fitur Utama

- **Customer Ordering (QR Code)**: Pemesanan menu langsung dari meja pelanggan via scan QR.
- **Admin Portal**: Kelola produk/menu, kategori, meja & QR code, akun staff, serta rekap/laporan penjualan.
- **Cashier (POS Portal)**: Manajemen transaksi kasir, penerimaan pembayaran (Tunai/QRIS), pencetakan struk, dan pengarsipan pesanan.
- **Kitchen Display System (KDS)**: Pantauan status pesanan dapur secara real-time.

## 🛠️ Tech Stack

- **Backend**: PHP 8.x, Laravel Framework
- **Frontend**: Blade Templating, TailwindCSS, Custom Responsive CSS
- **Database**: MySQL / MariaDB
